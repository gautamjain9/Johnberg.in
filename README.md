# Johnberg.in

A repo for Johnberg work.

## Connected work folders

This repository now includes two connected workspace folders:

- `claude-code-work/` → place work exported from Claude Code here.
- `johnberg-work/` → place the Johnberg project/work files here.

## How to use

1. Copy or move your Claude Code output into `claude-code-work/`.
2. Copy or move your Johnberg files into `johnberg-work/`.
3. Commit and push changes from this repository to keep both workstreams versioned together.
